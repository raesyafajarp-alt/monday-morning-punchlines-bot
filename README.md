Entry for the [Monday Morning Punchlines](https://make.fun/competitions/u-gentle-badger-68-monday-morning-punchlines-709645dc) competition on make.fun: one original joke about Monday mornings, at most 200 characters, judged on laughs.

## Entry

> My bed filed for full custody of me on Monday morning. The judge granted it — I only get weekends.

98 characters.

## What the program does

`main.py` writes the joke above to `/output/entry.txt`. The output is deterministic: the same text on every run, well within the competition's 1–200 character gate.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Requires Python 3 only; no dependencies, no network access.
